# 粮柿 Q-Persimmon · 项目一页纸 v0.1

- 日期：2026-10-28
- 状态：草案，待确认
- 关联：`docs/targets/target-genes.md`（靶基因清单 v0.1）

## 1. 一句话

把柿子从"高糖水果"改造成"高淀粉木本粮食"：抑制果实里的淀粉分解、加强淀粉合成，
让果实在成熟时仍以淀粉为主；保留乔木形态、多年生习性、耐旱耐瘠薄。

## 2. 目标对标：板栗，不是小麦

| 对标 | 判断 |
|---|---|
| 小麦 | 小麦能当主食靠的是**面筋蛋白**（能和水揉成面团）。柿子果实没有面筋蛋白，即使全是淀粉也揉不成面、发不起来。**形态上做不到** |
| 红薯 | 高糖 + 纤维 + 易发酵，吃多胀气"烧心"。**这正是要避免的**，说明"高淀粉"必须同时"低可溶性糖" |
| 板栗 | 木本、多年生、果实以淀粉为主、可蒸煮可制粉，历来号称"木本粮食"。**形态上完全对齐** |

**结论**：目标定义为**"板栗型"而非"小麦型"**——淀粉质、低糖、可蒸煮、可制粉；
"烧心"问题靠**降糖**解决，不是靠降淀粉。

## 3. 可测的目标性状

| 指标 | 现状 | 目标方向 |
|---|---|---|
| 成熟果淀粉含量 | 成熟果几乎不含淀粉，主要成分是糖 | 显著提高（具体数值待基线测量后再定） |
| 可溶性糖 | 高 | 降低 |
| 后熟软化 | 明显软化 | 延迟或抑制 |
| 株型 / 生活史 | 乔木、多年生 | 保持不变 |
| 抗逆性 | 耐旱耐瘠薄 | 保持 |

> 具体倍数不写死：没有基线数据之前写死数字，就是编。

## 4. 硬约束（路线设计的依据）

| 约束 | 现状 | 对路线的影响 |
|---|---|---|
| 实验条件 | 目前只有一台电脑，无实验室、无团队 | 自己动手做转化走不通，必须找合作方 |
| 柿属遗传转化 | 稳定转化与再生的公开报道极少，是公认瓶颈 | 柿子本身的基因编辑，1 年内不可能 |
| 木本结果周期 | 实生苗挂果以年计 | 果实表型验证按 3~5 年计 |
| 栽培柿倍性 | 六倍体 2n=6x=90 | 即使有平台，编辑难度也远高于二倍体 |
| 时间预期 | 希望 1 年内见结果 | 1 年内只能验证**假设**，不可能出**品种** |

## 5. 一年内唯一现实的路径

三条腿，缺一条就要降级：

| 阶段 | 做什么 | 谁来做 | 产出 |
|---|---|---|---|
| 第 1 步（1~2 月） | 用公开的柿及近缘种果实转录组，把 36 个靶点缩到 3 个 | 计算侧（不需要实验室） | 有优先级的短名单 |
| 第 2 步（1~3 月） | 找有番茄或烟草转化平台的课题组合作 | **只有这一步必须由你出面** | 一份合作协议，或至少一个愿意试的实验室 |
| 第 3 步（3~12 月） | 在番茄果实里敲掉对应淀粉酶，测淀粉与糖 | 合作方做实验 + 计算侧给设计 | 一张"敲掉之后淀粉留住了"的数据图 |

**为什么用番茄当验证宿主**：番茄是果实、有淀粉体、淀粉降解成糖的过程清楚、转化体系成熟，
是验证"果实里关掉淀粉酶能不能留住淀粉"最快的材料。柿子等有了平台再上。

## 6. 明确不做的事（边界）

- 不在栽培柿（六倍体）上做编辑
- 不做产量、株型、抗病等其它性状
- 不碰淀粉以外的代谢方向（单宁涩味、香气等）
- 不在没有表达数据的情况下指定"先改哪一个"靶点

## 7. 最大风险

**找不到愿意接手的转化平台。** 如果第 2 步失败，项目只能停在"计算 + 设计"阶段。
届时的备选：a) 用现有设计写综述或预印本，先把概念占住；b) 转向不需要遗传转化的方向。
