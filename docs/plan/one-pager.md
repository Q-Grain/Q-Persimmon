# 粮柿 Q-Persimmon · 项目一页纸 v0.3

- 日期：2026-10-28
- 状态：草案，待确认
- 关联：`docs/targets/target-genes.md`（靶基因清单 v0.1）

## 1. 一句话

把柿子从"高糖水果"改造成"高淀粉木本粮食"：抑制果实里的淀粉分解、加强淀粉合成，
让果实在成熟时仍以淀粉为主；保留乔木形态、多年生习性、耐旱耐瘠薄。

## 2. 目标对标：板栗，不是小麦

| 对标 | 判断 |
|---|---|
| 小麦 | 小麦能当主食靠的是**面筋蛋白**（能和水揉成面团）。柿子果实没有面筋蛋白，即使全是淀粉也揉不成面、发不起来。**形态上做不到** |
| 红薯 | 高糖 + 纤维 + 易发酵，吃多胀气"烧心"。**这正是要避免的**，说明"高淀粉"必须同时"低可溶性糖" |
| 板栗 | 木本、多年生、果实以淀粉为主、可蒸煮可制粉，历来号称"木本粮食"。**形态上完全对齐** |

**结论**：目标定义为**"板栗型"而非"小麦型"**——淀粉质、低糖、可蒸煮、可制粉；
"烧心"问题靠**降糖**解决，不是靠降淀粉。

### 2.1 科学目标的一句话表述

> **让果实在成熟时"淀粉不降"，而不是"重新合成淀粉"。**

两个说法听着接近，实现难度差一个数量级：

| 说法 | 可行性 | 原因 |
|---|---|---|
| 让成熟的果实重新合成淀粉 | ❌ | 淀粉合成只在幼果膨大期开窗口；成熟期合成机器已停工、淀粉粒已在降解，要求它重新合成等于要求果实不成熟 |
| 让果实在成熟时淀粉不降解 | ✅ | 马铃薯低温糖化已有商业先例：通过压制淀粉降解环节保住淀粉 |

### 2.2 必须接受的三个前提

1. **"糖化"不是一个步骤，是多条路径并行**：BAM、AMY、ISA、PUL、PHS、AGD 各管一段，只敲一个，其余会补上。
2. **因此必须同时压住多个靶点**，这也是必须用二倍体底盘（君迁子 2n=30）而不是六倍体栽培柿的原因。
3. **"改总开关"更彻底，但现在做不到**：调控果实成熟的开关在启动子和非编码区，现有数据只有编码区序列。

### 2.3 天然参考

柿属内已有"成熟但不软化"的现成类型——**完全甜柿（PCNA，如富有、次郎）**：在树上自然脱涩、果肉保持硬度。
但它们的淀粉**照样变成糖**，只是不软化。所以：

| 性状 | 柿属内有无天然范例 |
|---|---|
| 成熟不软化 | ✅ 有（PCNA 甜柿） |
| 成熟时淀粉不降解 | ❌ 没有，这是本项目要造的新性状 |

## 3. 可测的目标性状

| 指标 | 现状 | 目标方向 |
|---|---|---|
| 成熟果淀粉含量 | 成熟果几乎不含淀粉，主要成分是糖 | 显著提高（具体数值待基线测量后再定） |
| 可溶性糖 | 高 | 降低 |
| 后熟软化 | 明显软化 | 延迟或抑制 |
| 株型 / 生活史 | 乔木、多年生 | 保持不变 |
| 抗逆性 | 耐旱耐瘠薄 | 保持 |

> 具体倍数不写死：没有基线数据之前写死数字，就是编。

## 4. 硬约束（路线设计的依据）

| 约束 | 现状 | 对路线的影响 |
|---|---|---|
| 实验条件 | 一台电脑、一个人、无团队；**有公司主体**（可对公采购、可租用非住宅场地）；计划自建个人实验室 | 第 ① 档（组培、克隆、体外酶活、gRNA 切割）可以自己走；稳定转化仍需外部平台 |
| 柿属遗传转化 | 稳定转化与再生的公开报道极少，是公认瓶颈 | 柿子本身的基因编辑，1 年内不可能 |
| 木本结果周期 | 实生苗挂果以年计 | 果实表型验证按 3~5 年计 |
| 栽培柿倍性 | 六倍体 2n=6x=90 | 即使有平台，编辑难度也远高于二倍体 |
| **行业资源** | **无**：没有高校/院所/企业的合作渠道，本人为外行 | **整果表型验证在可预见期内无入口**；项目终点止于"技术能力 + 体外证据链 + 完整设计" |
| 时间预期 | 希望 1 年内见结果 | 1 年内只能验证**假设**，不可能出**品种** |

## 5. 一年内的路径：自主三条腿 + 外部一条腿

前提：已确认可以自建简易实验室（设备量级万元起步，需按实物询价核实）。

| 腿 | 做什么 | 依赖 | 回答什么问题 |
|---|---|---|---|
| 自主 A（1~2 月） | 建实验室、跑通流程 | 采购与调试 | —— |
| 自主 B（2~6 月） | 委托合成候选 CDS → 大肠杆菌/酵母表达 → 以柿果淀粉为底物体外测酶活 | 设备 + 时间 | 哪个淀粉酶在果实条件下真的拆得动淀粉 |
| 自主 C（4~8 月） | 设计 gRNA → 体外 Cas9 切割 → 电泳验证 | 设备 + 时间 | 设计到底切不切得动（对外说明最硬的一张图） |
| 自主 D（可选，6~12 月） | 烟草叶片瞬时表达柿子淀粉酶，看叶片淀粉是否下降 | 需光照培养架、农杆菌 | 在活植物细胞里也成立吗 |
| 外部 E（任意时点） | 果实层面表型验证 | **需转化平台（当前无入口，见第 4 节）** | 整果能不能留住淀粉 |

**关于番茄**：原方案用番茄做稳定转化，前提是当时假设没有任何实验条件。现在有体外与瞬时表达两条路，
番茄（会产生稳定转基因植株、周期 6~12 个月、家庭条件不合规）可以不做。它唯一不可替代的是
"整果层面"的数据，而那一步迟早要回到柿子上做。

**个人实验室的能力边界**（写清楚，避免把钱花在做不到的地方）：

| 层级 | 自主能做 | 备注 |
|---|---|---|
| 基因克隆、载体构建 | ✅ | |
| 大肠杆菌/酵母表达、体外酶活 | ✅ | 需分光光度计 |
| gRNA 体外切割 | ✅ | 需商用 Cas9 蛋白 |
| 烟草瞬时表达 | 🟡 边界 | 不产生稳定转基因植株，但属转基因操作 |
| 番茄/柿子稳定转化 | ❌ | 需组培间与资质 |
| 田间/多年生表型 | ❌ | 需场地与年数 |

## 6. 监管属性：算转基因，不是"不算"

| 层面 | 结论 |
|---|---|
| 科学/产品层面 | 可以做到最终植株**不含任何外源 DNA**（只留碱基级突变），这类常被称为 transgene-free gene-edited |
| **中国法规层面** | **算转基因**。农业农村部《农业用基因编辑植物安全评价指南（试行）》（2022）已把基因编辑植物纳入安全评价管理，没有"不插入外源基因即豁免"的通道 |
| 国际对比 | 美国 USDA 的 SECURE 规则对部分 SDN-1 类型可豁免；中国没有对应豁免 |

**时点**：安全评价不是项目后期的一次性手续，而是**逐阶段的门票**——进入下一阶段前必须先取得
上一阶段的批准。其中"实验研究"（第 I 阶段）是起点，**在开始稳定转化之前就要具备条件并提供
报告/备案**，不存在"先做出来再补手续"。

推论（对路线的影响）：

1. 任何**稳定转基因植株**（番茄转化、柿子转化）都要按转基因走安全评价，家庭条件不具备。
2. 要做到"最终不含外源 DNA"，需要额外一步：编辑后再通过自交/分离把 Cas9 等工具去掉。
   柿子是数年才开花结实的木本，这一步的时间成本以年计。
3. **体外实验与瞬时表达不产生转基因生物体**，是本阶段风险最低的路径——这也是路线把重心放在这两条上的原因。

> 本条只陈述公开法规事实，不构成法律意见；申报要求请以主管部门答复为准。

## 7. 明确不做的事（边界）

- 不在栽培柿（六倍体）上做编辑
- 不做产量、株型、抗病等其它性状
- 不碰淀粉以外的代谢方向（单宁涩味、香气等）
- 不在没有表达数据的情况下指定"先改哪一个"靶点

## 8. 最大风险（已是确认的约束，不是"可能"）

**没有行业资源，找不到愿意接手的转化平台。** 这不是概率问题——按当前条件，这一环没有入口。
因此项目在可预见期内的终点是：**技术能力 + 体外证据链 + 完整设计**，不含整果表型。

应对顺序：

1. 先在个人实验室做出体外证据（酶活、gRNA 切割），整理成技术报告或预印本——
   **这是没有资源的人唯一能自己造出来的信用**
2. **拿成果去找人**，而不是空手去谈合作
3. 长期选项：自己把转化能力建起来（公司 + 场地 + 至少一名有组培经验的员工），
   成本高、周期长，不属于 12 个月计划
