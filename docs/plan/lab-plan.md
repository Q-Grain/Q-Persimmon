## 1. 阶段 0：场地与安全（第 1 月）

### 场地

| 要求 | 说明 |
|---|---|
| 面积 | 15~25 m² 起步，一个房间即可 |
| 分区 | 洁净区（超净台 + 组培操作）与非洁净区（电泳、离心、配液）分开，最好两个房间或两端 |
| 温度 | 能稳定在 20~26℃（空调） |
| 电 | 至少 4~6 个插座，注意离心机、灭菌锅的功率 |
| 水 | 有上下水最好（洗瓶子是常态）；没有就准备大桶 + 废液桶 |
| 门 | 能关，减少灰尘与气流 |

### 安全（这不是形式，是必须做的）

| 项目 | 要求 |
|---|---|
| 高压灭菌锅 | 按压力容器操作，定期检查；不可无人看管 |
| 紫外灯 | 开启时人不可在场，配防护面罩 |
| 电泳染料 | 用 GelRed 类替代溴化乙锭，避免剧毒试剂 |
| 生物废弃物 | 菌液、培养基、组培污染瓶**必须高压灭菌后**再丢弃 |
| 化学废液 | 分开收集，不倒入下水道 |
| 试剂存放 | 乙醇、次氯酸钠远离热源，通风存放 |
| 记录 | 建一本实验记录本（纸质），每次操作记日期、批次、结果 |

## 2. 阶段 1：组培入门（第 1~3 月）

### 为什么先做这个
组培是植物转化的**前置技能**（转化 = 导入基因 + 把细胞重新长成植株）。练的是无菌操作手感，与后面所有实验共用。

### 材料（按难度递增）

| 顺序 | 材料 | 理由 |
|---|---|---|
| 1 | 烟草（*Nicotiana tabacum* 或 *N. benthamiana*） | 种子易得、再生容易、污染容忍度较高 |
| 2 | 番茄 | 与后续验证宿主一致，可衔接 |
| 3 | 草莓或兰花 | 练手趣味性高，成活率直观 |

**不要**一开始用柿子——柿属再生困难是物种固有门槛，失败周期以月计，学不到东西。

### 要买什么
- 预混 MS 培养基（含蔗糖与琼脂，直接加水溶解）——**强烈建议买预混**，自己配二十多种母液容易出错
- 植物激素（6-BA、NAA、IBA）少量
- 组培瓶/培养盒、封口膜
- 解剖器械（镊子、手术刀、剪刀）
- 次氯酸钠（有效氯 1% 工作液）、75% 乙醇
- 光照培养架（LED + 定时器，16 h 光 / 8 h 暗）

### 操作流程（每次一样）
1. 种子或外植体表面消毒：75% 乙醇 30~60 s → 1% 次氯酸钠 10~20 min → 无菌水冲洗 3~5 次
2. 超净台内接种到培养基
3. 25℃、16 h 光照培养
4. 每 3~4 周继代一次

### Gate 1 判定
- 连续 3 批中至少 1 批**无细菌/真菌污染**
- 能完成**一次继代**且新苗存活

前两个月大概率报废几批，属正常，不算失败。

## 3. 阶段 2：分子基本功（第 2~5 月）

### 要掌握的四个动作
| 动作 | 判定标准 |
|---|---|
| DNA 提取 | 能提出可跑胶的高分子量 DNA |
| PCR | 能扩出预期大小的条带 |
| 琼脂糖电泳 | 能正确判读条带大小与亮度 |
| 大肠杆菌转化 + 质粒提取 | 能从单菌落提出质粒并跑胶验证 |

### 一个有时间窗口的动作：保存本地材料
**现在（10~11 月）就做**：采当地柿子（磨盘柿）或君迁子的幼果/叶片，两种方式各存一份：
- 剪碎后装入离心管，**-20℃ 冻存**
- 硅胶干燥保存（室温，可长期）

用途：后续提 DNA（验证 gRNA 靶点是否存在）与提 RNA（判断基因在果实里是否表达）。**过了季节就要等一年。**

### 要买什么
- Taq 或高保真酶预混液、dNTP、引物合成服务
- 琼脂糖、电泳缓冲液、DNA 分子量标准
- 感受态细胞（DH5α）、质粒提取试剂盒、胶回收试剂盒
- 抗生素（氨苄/卡那）、LB 培养基原料

## 4. 阶段 3：gRNA 体外切割（第 4~8 月）

这是全计划里**最容易出漂亮结果**的一步，也是谈合作时最硬的一张图。

### 关键现实问题：你没有柿子 DNA
模板有两种解法，建议**先用 A 保证流程跑通**：

| 方案 | 做法 | 优点 |
|---|---|---|
| A（推荐先做） | 委托合成靶点附近 **600~800 bp 双链 DNA 片段**（序列取自 `data/targets/starch_genes.cds.fna`） | 不用提 DNA，立刻能开始，成本低 |
| B（并行） | 用冻存的本地材料提 DNA，PCR 扩增同一区域 | 用的是真实本地序列，更有说服力 |

### 流程
1. 从短名单基因的 CDS 中选 20 nt 靶序列（要求：紧邻 NGG）
2. 设计工具用公开的植物专用平台（如 CRISPR-P、CHOPCHOP、CRISPOR），**同时检查脱靶**
3. 委托合成 gRNA（或体外转录）
4. 商用 Cas9 蛋白 + gRNA + 目标片段，37℃ 孵育 1 h
5. 跑琼脂糖胶，看是否出现两条预期大小的切割条带

### Gate 3 判定
- 出现**两条预期大小**的条带（不是弥散、不是没切）
- 阴性对照（不加 Cas9）只有一条完整条带

## 5. 阶段 4：表达 + 体外酶活（第 5~10 月）

### 流程
1. 委托合成候选淀粉酶的 CDS（可直接加 His 标签），克隆进表达载体
2. 转入 BL21(DE3)，IPTG 诱导表达
3. 裂解（超声破碎；没有超声仪可用溶菌酶 + 反复冻融）
4. 测酶活

### 测活怎么做
| 方法 | 原理 | 需要 |
|---|---|---|
| DNS 法 | 酶切淀粉产生还原糖，显色后测 540 nm 吸光 | 分光光度计 + DNS 试剂 |
| 碘染法 | 淀粉遇碘变蓝紫，酶降解放淀粉则褪色 | 碘-碘化钾 + 目视/拍照 |

**底物**：先用可溶性淀粉或马铃薯淀粉做初筛；拿到真实结论要用**柿果淀粉**（可由青柿子自制）。

### 条件必须自己摸索
不同来源的 β-淀粉酶最适 pH 与温度差异很大。第一轮按梯度做：
- pH：4.5 / 5.0 / 5.5 / 6.0 / 6.5 / 7.0
- 温度：30 / 40 / 50 / 60 ℃

### Gate 4 判定
- 与**空载对照**相比，还原糖释放（或碘染褪色）有稳定、可重复的差异
- 至少 3 次独立重复

## 6. 阶段 5：烟草瞬时表达（可选，第 8~12 月）

- 目的：验证"在活植物细胞里，这个酶是否也拆淀粉"
- 做法：农杆菌 GV3101 携带表达载体 → 注射烟草叶片 → 3~5 天后叶片碘染
- 判定：注射区碘染明显浅于对照区
- 不做也不影响前四步成果

## 7. 采购清单（分三批，量级万元起，具体按实物询价）

### 第一批（第 1 月，跑通组培 + PCR）
| 类别 | 物品 |
|---|---|
| 移液 | 0.5-10 / 20-200 / 100-1000 µL 各一支 + 枪头 |
| 离心 | 台式高速离心机（1.5/2 mL，≥12000×g）、涡旋振荡器 |
| 温控 | PCR 仪、恒温培养箱（37℃）、磁力搅拌器、水浴锅 |
| 电泳 | 水平电泳槽 + 电源 + 制胶模具 + 蓝光或紫外透射台 |
| 称量 | 电子天平（0.001 g） |
| 其他 | 微波炉、pH 计、冰箱（4℃/-20℃）、超纯水或纯水 |
| 组培 | **超净工作台**、**高压灭菌锅**、MS 预混培养基、组培瓶、器械、光照架 |

### 第二批（第 3 月，跑通细菌培养与质粒）
恒温摇床、菌种保存用甘油、抗生素、LB 原料、质粒提取/胶回收试剂盒、-20℃ 冰盒

### 第三批（第 5 月，跑通测活）
可见光分光光度计（或酶标仪）、DNS 试剂或碘-碘化钾、超声破碎仪（可用冻融替代）、Cas9 蛋白

## 8. 最可能失败的地方（提前知道就不慌）

| 问题 | 概率 | 应对 |
|---|---|---|
| 组培污染，连续报废 | 高（前 3 月必然发生） | 严格分区、器械灼烧、勤换封口膜；一次只开一个瓶 |
| 蛋白表达全是包涵体 | 中 | 降低诱导温度（16~20℃）、降低 IPTG 浓度、延长诱导时间 |
| 酶活测不出差异 | 中 | 先做 pH/温度梯度；换底物；加酶量提高 |
| 采购到货慢拖乱节奏 | 高 | 第一批一到就先做组培，不等等齐 |
| 一个人做，记录丢失 | 中 | 强制纸质记录本 + 每步拍照 |
