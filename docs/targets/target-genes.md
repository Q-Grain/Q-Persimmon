## 2. 先认识几个词

柿子后熟变软变甜，本质是**淀粉被拆成糖**。所以这个项目就是两件事：

| 名词 | 大白话 | 我们要做什么 |
|---|---|---|
| 淀粉 | 储存起来的"糖砖块" | 留得多 → 能当饭吃 |
| 淀粉酶（BAM / AMY） | 拆砖块的刀 | **关小** |
| 脱支酶（ISA / PUL） | 先把砖块堆的"绑绳"解开，刀才砍得动 | **关小** |
| 磷酸化酶（PHS） | 另一种拆砖方式 | **关小** |
| AGPase | 把糖变砖的第一道工序，公认的"总闸门" | **开大** |
| GBSS（Waxy） | 决定砖块是"直着码"还是"岔着码" | **开大** |
| SSS / SBE | 把砖块码长、码出岔 | **开大** |

## 4. 磨盘柿（六倍体）对照：这一栏现在是空的

你要求把当地磨盘柿作为对照单列一栏。**目前给不出可行的对照数据，原因如下**，不是我漏了：

| 物种 | 倍性 | 在本项目里的角色 | 数据状态 |
|---|---|---|---|
| 君迁子 *D. lotus* | 2n = 2x = 30 | 设计图纸（编辑底盘） | ✅ 已有：`GCF_014633365.1` |
| 磨盘柿 *D. kaki*（盘山当地） | **2n = 6x = 90** | 表型对照 / 未来推广对象 | ❌ 缺：没有六倍体基因组组装，无法列出它对应的拷贝 |
| 油柿 *D. oleifera* | 2n = 2x = 30 | 已排除（亚热带树种，抗寒不足，华北不适宜露地栽培） | 不需要 |

关键点：磨盘柿是六倍体，**同一个基因在它体内理论上存在 6 份相似但不相同的拷贝**。把君迁子的基因编号直接套过去是错的，必须拿到 *D. kaki* 自己的组装和注释，才有意义地做这张对照表。

## 5. 36 个里先做哪几个？——现在还定不了

定不下来不是数据不好，是**缺一个关键东西：表达数据**。

道理很简单：注释只告诉我们"基因组里有这个基因"，但没告诉我们"果肉里这个基因开不开、开多大"。柿子有 8 个 β-淀粉酶基因，真正在后熟果肉里干活的可能只有 1~2 个，敲错的那 6 个不会有效果。

**要补的东西**：一份果实三个时期的转录组（青果 / 膨大期 / 后熟期），两两比较就能把 36 个缩到 2~3 个。

在那之前，唯一能基于现有数据说的一句：**定位于质体/淀粉体的那几个（BAM1、BAM3、ISA3、PHS L-1、AGPase 大亚基、GBSS1）比其它候选更值得先看**——因为果实里的淀粉就存在淀粉体里，酶得进得去才拆得动。

## 6. 已知问题（诚实清单）

1. **α-淀粉酶可能漏注**：只找到 3 个，番茄有 4 个以上、水稻 8 个以上，这个数字偏低，后续要用蛋白序列回补。
2. **全部是自动预测模型**：41,937 条里 `NM_`（人工审校）为 0，全部 `XM_`，个别基因名可能与真实功能有出入。
3. **5 个模型不能直接用**：`LOC127789021`（342 bp）、`LOC127805799`（501 bp）残缺；`LOC127791979`、`LOC127811704`、`LOC127788733` 注释为无活性蛋白。
4. **只有编码区序列**：没有启动子、UTR、内含子。所以**只能改"酶本身"，不能改"开关"**（比如想让某个基因在果实里更活跃，暂时做不到）。
5. **未纳入的调控因子**：质体淀粉降解还受 GWD / PWD / SEX4 / LSF 等磷酸化调控蛋白控制，本清单暂未收录，属于下一轮扩展。
