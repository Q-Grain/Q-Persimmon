# 粮柿 · Q-Persimmon

巧稷计划（Q-Grain）首发物种。

**一句话**：把柿子从"高糖水果"改造成"高淀粉主粮"——抑制果实里的淀粉分解、加强淀粉合成，
让果实在成熟时把淀粉留在里面而不是全变成糖；保留乔木形态和多年生习性，一次种植收获数十年，
目标是在山地、边际土地上稳定产出能当饭吃的果实。

## 和盘山当地柿子的关系

| 物种 | 倍性 | 角色 |
|---|---|---|
| 磨盘柿（盖柿）*D. kaki*，盘山/蓟州主栽，国家地理标志产品 | **六倍体 2n=6x=90** | 表型对照 + 未来推广对象，**不是**编辑底盘 |
| 君迁子 *D. lotus* | 二倍体 2n=30 | 当前的设计对象（也是磨盘柿常用的砧木） |
| 油柿 *D. oleifera* | 二倍体 2n=30 | 备选底盘 |

> 六倍体里同一基因有 6 份相似拷贝，无法直接把君迁子的基因编号套用过去。

## 术语速查

| 词 | 大白话 |
|---|---|
| 淀粉 / 糖 | 淀粉是"糖砖块"，糖是散装糖；柿子后熟就是把砖块拆成散糖 |
| BAM / AMY | 拆砖的刀（β-淀粉酶 / α-淀粉酶），本项目中要**关小** |
| ISA / PUL | 先解开砖堆的绑绳，刀才砍得动（脱支酶），要**关小** |
| AGPase | 把糖变砖的第一道工序，公认的"总闸门"，要**开大** |
| GBSS / SSS / SBE | 把砖码长、码岔的机器，要**开大** |

## 已知限制

1. 注释全部为自动预测（`XM_`），无人工审校（`NM_`）。
2. α-淀粉酶仅注到 3 个，疑有漏注。
3. 5 个基因模型不可直接使用（2 个残缺、3 个无活性蛋白），详见主文档第 6 节。
4. 只有编码区序列，无法针对启动子/内含子做表达调控编辑。
